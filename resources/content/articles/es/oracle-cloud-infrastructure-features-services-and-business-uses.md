Oracle Cloud Infrastructure (OCI) es la plataforma de computación en la nube de Oracle para ejecutar aplicaciones, bases de datos, cargas de trabajo de análisis, inteligencia artificial, redes, almacenamiento e infraestructura empresarial. Ofrece capacidades de infraestructura como servicio y de plataforma como servicio que las organizaciones pueden utilizar para migrar sistemas existentes, crear nuevas aplicaciones y operar cargas de trabajo empresariales en la nube.

OCI incluye más de 200 servicios en la nube en sus distintas regiones, que abarcan cómputo, almacenamiento, redes, bases de datos, contenedores, herramientas para desarrolladores, IA, análisis, seguridad, observabilidad y gobernanza. Oracle también ofrece opciones de implementación híbrida, multinube y en nube dedicada para organizaciones con requisitos especializados de infraestructura o de residencia de datos.

La plataforma está especialmente integrada con el ecosistema de bases de datos y aplicaciones empresariales de Oracle, aunque las organizaciones también pueden usar OCI para cargas de trabajo en la nube de uso general y para aplicaciones creadas con tecnologías de código abierto.

## ¿Qué es Oracle Cloud Infrastructure?

OCI proporciona la infraestructura subyacente y los servicios gestionados necesarios para ejecutar aplicaciones y plataformas de datos. Las organizaciones pueden aprovisionar máquinas virtuales, servidores bare-metal, almacenamiento, redes, bases de datos, contenedores y otros recursos a través de la Oracle Cloud Console, las API, las herramientas de línea de comandos y los servicios de infraestructura como código.

Oracle organiza OCI en categorías que incluyen cómputo, almacenamiento, redes, bases de datos, contenedores, servicios para desarrolladores, IA y aprendizaje automático, análisis, seguridad y gobernanza.

Las empresas pueden utilizar estos servicios de forma individual o combinarlos en arquitecturas de aplicaciones más amplias.

## OCI Compute

OCI Compute ofrece máquinas virtuales e instancias bare-metal para ejecutar aplicaciones y cargas de trabajo.

Las configuraciones de máquinas virtuales pueden elegirse en función de la CPU, la memoria, el almacenamiento y los requisitos de cada carga de trabajo. OCI también ofrece instancias basadas en Arm, recursos de computación de alto rendimiento y cómputo acelerado por GPU para cargas de trabajo exigentes.

Oracle admite tanto infraestructura virtualizada como bare-metal, lo que permite a las organizaciones elegir un entorno según sus necesidades de rendimiento, aislamiento y aplicaciones.

Los recursos de cómputo pueden integrarse con los servicios de redes, almacenamiento en bloques, balanceo de carga, supervisión y seguridad de OCI.

## Servicios de almacenamiento

OCI ofrece varias opciones de almacenamiento para distintos requisitos de aplicaciones.

Object Storage está diseñado para datos no estructurados, como copias de seguridad, contenido multimedia, archivos de aplicaciones y cargas de trabajo de lagos de datos. Block Volumes proporciona almacenamiento persistente que puede conectarse a instancias de cómputo, mientras que File Storage ofrece acceso a sistemas de archivos compartidos.

OCI también ofrece Archive Storage para datos a los que se accede con menos frecuencia, pero que deben conservarse durante periodos más largos.

Estos servicios permiten a las empresas organizar sus necesidades de almacenamiento según los requisitos de rendimiento, accesibilidad y conservación.

## Servicios de bases de datos de Oracle

Las bases de datos son una de las principales áreas de especialización de OCI.

La plataforma admite Autonomous AI Database, Exadata Database Service, Base Database Service, MySQL HeatWave, NoSQL Database, PostgreSQL y otras tecnologías de bases de datos.

Autonomous AI Database automatiza muchas tareas de administración de bases de datos y puede dar soporte al procesamiento de transacciones, el análisis, las cargas de trabajo JSON y el desarrollo de aplicaciones.

OCI también ofrece servicios basados en Exadata para organizaciones que ejecutan cargas de trabajo exigentes en bases de datos de Oracle. Las empresas pueden usar estos servicios para trasladar sus bases de datos de Oracle a la infraestructura en la nube sin perder la compatibilidad con sus entornos de bases de datos consolidados.

## Redes

OCI ofrece servicios de red basados en Virtual Cloud Networks (VCN).

Las organizaciones pueden crear redes virtuales aisladas y configurar subredes, enrutamiento, reglas de seguridad, puertas de enlace, balanceadores de carga y otros componentes de red.

FastConnect proporciona conectividad dedicada entre los entornos del cliente y OCI, mientras que los servicios de VPN ofrecen conectividad cifrada a través de internet pública. OCI también ofrece DNS, cortafuegos de red, puertas de enlace de servicio y puntos de conexión privados.

Estas capacidades dan soporte a arquitecturas que van desde aplicaciones individuales en la nube hasta entornos empresariales híbridos.

## Contenedores y Kubernetes

OCI respalda el desarrollo de aplicaciones nativas de la nube mediante servicios gestionados de contenedores.

Oracle Kubernetes Engine (OKE) proporciona infraestructura de Kubernetes gestionada, mientras que Container Instances permite a las organizaciones ejecutar contenedores sin administrar los servidores subyacentes.

OCI también ofrece Container Registry para almacenar y gestionar imágenes de contenedores, así como Functions para cargas de trabajo de aplicaciones sin servidor.

Esta combinación puede dar soporte a microservicios, API, aplicaciones basadas en eventos y aplicaciones que necesitan escalar de forma independiente.

## Servicios para desarrolladores y DevOps

OCI incluye herramientas para el desarrollo de aplicaciones, la automatización de infraestructura y la entrega de software.

OCI DevOps ofrece capacidades de integración y entrega continuas, mientras que Resource Manager proporciona automatización gestionada de infraestructura basada en Terraform.

Los desarrolladores también pueden utilizar API Gateway, Events, Queue, Streaming, Notifications, Functions y otros servicios para crear aplicaciones distribuidas y arquitecturas basadas en eventos.

Estos servicios permiten a los equipos de desarrollo automatizar la implementación de infraestructura y aplicaciones sin depender por completo de recursos en la nube configurados manualmente.

## IA y aprendizaje automático

OCI ofrece un conjunto creciente de servicios de IA y aprendizaje automático.

OCI Generative AI da acceso a grandes modelos de lenguaje para tareas como la generación de texto, la elaboración de resúmenes y los embeddings. Las empresas pueden utilizar los embeddings para búsquedas semánticas, clasificación, sistemas de recomendación y otras aplicaciones de IA.

OCI también ofrece servicios de IA para voz, lenguaje, visión y comprensión de documentos. OCI Data Science proporciona un entorno en el que los científicos de datos pueden desarrollar, entrenar, implementar y supervisar modelos de aprendizaje automático con Python y herramientas de código abierto.

Las organizaciones también pueden utilizar cómputo basado en GPU para las cargas de trabajo de IA más exigentes.

## Servicios de análisis y datos

OCI ofrece servicios de análisis, integración de datos, streaming y procesamiento de big data.

Data Flow proporciona capacidades gestionadas de Apache Spark, mientras que Data Integration facilita el movimiento y la transformación de datos. OCI Streaming ofrece una plataforma gestionada para ingerir y consumir flujos de eventos de gran volumen.

Oracle también ofrece servicios de análisis capaces de conectar los datos empresariales con los flujos de trabajo de informes e inteligencia de negocio.

Estas capacidades pueden dar soporte a almacenes de datos, lagos de datos, análisis operativo y procesamiento en tiempo real.

## Seguridad e identidad

Los controles de seguridad están integrados en todos los servicios de infraestructura y aplicaciones de OCI.

Las organizaciones pueden utilizar políticas de gestión de identidades y accesos para controlar quién puede acceder a los recursos en la nube. OCI también ofrece Web Application Firewall, Key Management, Vault, supervisión de la seguridad, registro de actividad y capacidades de Cloud Guard.

OCI Vault proporciona claves de cifrado gestionadas por el cliente, mientras que los servicios de seguridad pueden ayudar a las organizaciones a supervisar configuraciones e identificar riesgos potenciales.

Estos controles pueden combinarse con políticas de red y conectividad privada para crear entornos en la nube restringidos.

## Implementaciones híbridas y multinube

OCI va más allá de las implementaciones tradicionales en la nube pública.

Oracle ofrece Cloud@Customer, Dedicated Regions y otras opciones de nube distribuida para organizaciones que necesitan infraestructura en la nube en ubicaciones concretas o bajo determinadas restricciones operativas.

OCI también admite conectividad multinube. Oracle ofrece servicios de bases de datos y conectividad con AWS, Microsoft Azure y Google Cloud, lo que permite a las organizaciones combinar los servicios de Oracle con la infraestructura de otros proveedores de nube.

Esto puede resultar útil para las empresas que operan aplicaciones en varios entornos de nube.

## Precios de OCI y nivel gratuito

OCI aplica por lo general precios basados en el consumo, con costes que varían en función del cómputo, el almacenamiento, las redes, los recursos de bases de datos y otros servicios.

Oracle también ofrece un nivel Always Free con recursos que siguen siendo gratuitos durante toda la vida de una cuenta elegible. Los recursos Always Free actuales incluyen dos instancias de Autonomous AI Database de 20 GB cada una, recursos de cómputo, almacenamiento, un balanceador de carga flexible y 10 TB de transferencia de datos saliente al mes.

Los nuevos usuarios pueden recibir además 300 dólares en créditos gratuitos durante 30 días para servicios elegibles.

Oracle ofrece un Cost Estimator para calcular los gastos mensuales previstos de infraestructura. Los Universal Credits también pueden aportar flexibilidad a las organizaciones que consumen varios servicios de OCI.

## Usos empresariales de OCI

Las organizaciones pueden utilizar OCI para una amplia variedad de cargas de trabajo, entre ellas:
* Migración de bases de datos de Oracle
* Alojamiento de aplicaciones empresariales
* Aplicaciones web y de API
* Almacenes de datos y análisis
* Cargas de trabajo de IA y aprendizaje automático
* Kubernetes y aplicaciones en contenedores
* Copias de seguridad y recuperación ante desastres
* Computación de alto rendimiento
* Infraestructura de nube híbrida
* Procesamiento de datos en tiempo real
* Desarrollo de aplicaciones empresariales

Por tanto, OCI puede dar soporte tanto a las cargas de trabajo empresariales existentes como a las aplicaciones nativas de la nube más recientes.

## Cómo evalúan las empresas OCI

Por lo general, las organizaciones tienen en cuenta:
* La infraestructura existente de bases de datos y aplicaciones de Oracle
* Los requisitos de cómputo y almacenamiento
* La arquitectura en la nube
* El rendimiento de las bases de datos
* Las redes y la conectividad
* La seguridad y el cumplimiento normativo
* Los requisitos de IA y análisis
* Los requisitos multinube
* Las consideraciones sobre residencia de datos
* El consumo previsto y el coste total

Las empresas deben evaluar tanto los servicios individuales como la arquitectura necesaria para operar la carga de trabajo completa.

## Reflexiones finales

Oracle Cloud Infrastructure ofrece una amplia plataforma en la nube que abarca cómputo, almacenamiento, redes, bases de datos, contenedores, IA, análisis, seguridad y servicios para desarrolladores. Sus capacidades de bases de datos e infraestructura empresarial la hacen especialmente relevante para las organizaciones que ya operan cargas de trabajo de Oracle, mientras que sus servicios de cómputo de uso general, Kubernetes, computación sin servidor e IA pueden dar soporte a arquitecturas en la nube más amplias.

La plataforma también ofrece recursos Always Free, créditos de prueba, precios basados en el consumo, opciones de implementación híbrida y servicios multinube. Las empresas que evalúan OCI pueden comparar estas capacidades con su infraestructura actual, los requisitos de sus aplicaciones, sus políticas de seguridad y el consumo de nube que prevén.
