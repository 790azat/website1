## Overview

Tableau functions as "a visual analytics and business intelligence platform that helps users explore data and create interactive visualizations." Organizations leverage it to transform data into actionable insights across multiple departments.

## Core Products

The platform encompasses several offerings:
* Tableau Desktop: Local analysis and workbook development
* Tableau Cloud: Hosted analytics with Standard, Enterprise, and Cloud+ editions
* Tableau Server: Self-managed deployment option
* Tableau Prep: Data cleaning and preparation tools

## Pricing Structure

Tableau Cloud Standard pricing (annual billing):
* Creator: $75/user/month
* Explorer: $42/user/month
* Viewer: $15/user/month

Enterprise tier costs more, while Cloud+ involves custom pricing with enhanced AI capabilities.

## Key Capabilities

The platform supports "data connectivity," "interactive data visualization," dashboard creation, and "visual exploration" across various business functions including finance, sales, operations, and management reporting.

## AI Integration

Newer versions incorporate Tableau Agent and Tableau Pulse for "AI-assisted and agentic analytics capabilities," though organizations should evaluate data governance implications.

## Evaluation Factors

Businesses should consider data source compatibility, visualization requirements, deployment preferences, security needs, user role estimation, scalability, and total cost of ownership.
