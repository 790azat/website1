## Overview

Organizations require analytics platforms capable of integrating data from multiple systems, preparing information for analysis, and delivering insights across technical and business audiences. Oracle Analytics addresses this need through "data connectivity, preparation, modeling, visualization, reporting, machine learning, and collaboration."

The Oracle Analytics portfolio encompasses Oracle Analytics Cloud (OAC) for cloud deployments and Oracle Analytics Server (OAS) for on-premises or private-cloud environments, both supporting governed reporting, self-service analytics, data discovery, and augmented analytics capabilities.

## Key Capabilities

## Data Connectivity and Preparation

The platform connects to databases, cloud services, spreadsheets, CSV files, and legacy systems via JDBC. Users can profile, cleanse, transform, and enrich data before analysis without repeatedly exporting to separate applications.

## Data Modeling

Semantic models provide consistent business definitions and abstract underlying data sources, allowing analysts simplified exploration while establishing uniform metrics and KPIs across departments.

## Visualization and Reporting

Interactive tools enable dashboard creation, charting, mapping, and multi-page organization. The platform supports both exploratory analysis and structured enterprise reporting, including pixel-perfect reporting capabilities.

## AI and Machine Learning

One-click analytics generate forecasts, trends, and clusters. Generative AI assistants enable natural-language task descriptions that translate into platform actions, reducing manual configuration requirements.

## Deployment Options

Oracle Analytics Cloud provides cloud-native deployment through Oracle Cloud Infrastructure with managed service functions, supporting capacity adjustments and connections to on-premises data sources.

Oracle Analytics Server delivers comparable capabilities for organizations requiring on-premises control, supporting regulated environments and multi-cloud architectures.

## Business Applications

The platform serves multiple organizational functions: financial performance monitoring, sales analytics, operations KPI tracking, HR workforce analysis, and executive dashboards providing consolidated organizational metrics.

## Pricing Structure

Oracle offers Professional and Enterprise editions through user-per-month or Oracle Compute Unit (OCPU) hourly models. Published pricing indicates approximately "$20.97 per user per month for Professional and $104.85 per user per month" for Enterprise, though regional variation and additional services affect actual costs.

## Evaluation Considerations

Organizations should assess data source requirements, deployment architecture needs, governance standards, self-service analytics scope, AI capabilities alignment, and total cost of ownership including implementation and administration.
